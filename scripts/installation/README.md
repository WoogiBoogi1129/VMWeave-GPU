# 검증 환경의 설치 보조 자료

2026-09-21~22 실험에 사용한 설치 설정·probe·호스트 복구 스크립트입니다.
기존 `docs/installation/`에서 이동했습니다. 당시 실행 기록은
[역사 설치 보고서](../../legacy/docs/installation/INSTALLATION_REPORT_2026-09-22.md)에 있습니다.

전제로 합니다. 일반 설치기로 자동 실행하지 않습니다.
현재 준비 순서는 [GPU 안내](../../docs/getting-started/gpu.md)를 따릅니다.
