# 이전 결과 보존

`v0.5.11/`은 갱신 전 보고서·분석 결과를 원본 바이트 그대로 보존한다.
기존 원자료, 실행 증거, 프로토콜, 측정 소스는 상위 디렉터리의 원래 경로에 남아 있다.
중복 저장하지 않은 파일의 해시는 `v0.5.11/preserved-original-files.json`에 기록했다.

`v0.5.11/SHA256SUMS`는 당시의 경로를 사용하는 **원본 manifest**다.
현재 루트에서 직접 검사하면 교체된 분석 파일 때문에 불일치가 발생한다.
현재 검증 명령 `../scripts/verify_refresh.py`는 보존된 분석 파일은 이력 경로에서,
원자료·프로토콜·측정 소스는 원래 경로에서 검사한다.
현재 공개 묶음 전체의 무결성은 상위 디렉터리의 새 `SHA256SUMS`로 검사한다.

현재 비교에는 기존 Native·Flyt·Lupine만 유지하며, 이전 VMWeave는 제외한다.
보고서 열람에는 상위 디렉터리의 `REPORT-v0.5.11.md`를 사용한다.
