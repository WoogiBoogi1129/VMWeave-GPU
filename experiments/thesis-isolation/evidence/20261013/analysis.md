# 원 성능 경합 실험 — 7번 집계 결과

현재 계획서에서 재번호화한 데이터 접근 격리 E2와 구분되는, 대화에서 승인한 성능 실험이다.

방향별 5회, 30구간을 원시 요청 기록으로 재계산했다. 총 381,945건 정상 완료, 오류 0건, 결과 불일치 0건. 모든 구간이 1,260초 이상이며 10,000건을 충족했다. 세션 20개 회수 기록을 확인했다.

## 계산과 검증

- p99는 각 구간 정상 요청 지연시간의 nearest-rank 99백분위수이며 표는 그 반복별 값의 평균이다. 전체 요청을 합친 p99가 아니다.
- 처리량은 정상 완료 수/관측 경과 시간이다. 지연시간은 GPU forward와 동기화까지이며, 정확성 확인을 위한 CPU 전송·비교는 지연시간에서 제외되고 처리량의 경과 시간에는 포함된다.
- 변화율은 동일 반복의 기준 조건과 짝지어 계산한 뒤 평균했다. 원시 수치와 기존 results.json의 일치, 요청 ID 연속성, 구간 길이, 조건 수, 역할별 반복 수를 확인했다.
- 경합 조건은 부하 시작/종료의 호스트 수신 시각이 관측 구간을 포함하고 실제 커널 완료 수가 양수임을 확인했다. 수신 시각에는 통신 지연이 포함된다.
- per-run.csv에 반복별 값, summary.json에 평균·최솟값·최댓값·표본 표준편차, source-sha256.json에 입력 증거 해시를 보존했다.

## 해석 범위

- 표본 수 목표는 충족했지만 요청 간 자기상관과 방향별 5회라는 반복 수 제한이 있다. 신뢰구간이나 통계적 유의성을 주장하지 않는다.
- 이 결과는 해당 MLP, 부하 구현, VM 배치와 할당량에서의 관측이다. 부하가 GPU 대역폭/연산을 포화시켰다는 증거 또는 모든 작업의 격리 보장은 아니다.
- 서비스 SLA가 없어 적합성은 INCONCLUSIVE다. 메모리 접근 차단·기밀성·무결성 경계를 검증한 결과로 해석하지 않는다.
- 8번의 스크린샷·최종 보고서·GitHub 반영은 이 집계에 포함하지 않았다.
