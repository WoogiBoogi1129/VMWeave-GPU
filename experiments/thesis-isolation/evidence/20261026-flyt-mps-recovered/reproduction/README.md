# 실행 기록과 재현 범위

이 폴더는 실제 사용한 실행기와 템플릿을 보존한다. `measure-v1.py`는 원 캠페인 첫 3회, `measure.py`는 나머지 7회에 사용했다. `run.py`의 현재 사본을 새로 실행하면 모든 회차에 현재 `measure.py`가 적용되므로 과거 절차 차이를 그대로 재현하는 명령은 아니다.

GPU 실험 재실행에는 별도 시험 클러스터, 기록된 이미지와 번들, 독립 호환 빌드, VM SSH 설정 및 실행 ID별 경로 준비가 필요하다. 이들은 보편적인 즉시 실행 스크립트가 아니며 기존 실험 경로에서 그대로 재실행하면 안 된다. 자격증명과 대형 바이너리는 포함하지 않는다.

공개 원시 자료에서 표·그래프·보고서를 재생성하는 분석 명령은 상위 REPORT.md를 따른다. 분석에는 GPU나 실험 환경 접근이 필요하지 않다.
