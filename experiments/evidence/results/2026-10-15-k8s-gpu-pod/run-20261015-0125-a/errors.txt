오류 및 조치 기록 — 2026-10-15 KST

본 GPU Pod 실행은 1회이며 실패·CUDA 오류·컨테이너 재시작이 없었다.
준비 및 관측 도구에서 발생한 문제는 GPU 동작 실패와 구분한다.

E01: Playwright 기본 모듈 탐색 실패 → 기존 설치 위치를 NODE_PATH로 지정. 실제 화면 6장 캡처 성공.
E02: Guest OCI 이미지 반입 도구 부재 → Podman 설치 및 이미지 반입. CRI-O가 동일 digest의 로컬 이미지를 사용함을 확인.
E03: crictl 미설치로 초기 조회 실패 → kubectl JSON과 Podman 조회로 대체. 불필요한 crictl 설치는 하지 않음.
E04: C 코드 들여쓰기 경고 → 중괄호와 줄 분리로 수정, -Wall -Wextra -Werror 빌드 통과.
E05: Pod 생성 전 수집기의 NotFound 2건 → 원본 보존, --ignore-not-found와 빈 응답 대기 처리를 추가. 정리 후 없는 Pod 조회가 exit 0인 것을 확인.

미해결 오류: 0. E05 수집기 수정은 GPU 기능 변경이 아니며 추가 GPU 실행 없이 조회 명령으로 검증했다.
초기 E01/E03/E04 메시지는 준비 당시 도구 출력에 근거한 전사 기록이며, 원본 실패 화면을 촬영했다고 주장하지 않는다.
상세 원인·해결·근거 파일은 errors.json을 참조한다.

E06: 오프라인 검증기의 시간 판정 오류 → 생성 요청 시작과 응답 완료를 혼동해, 생성 요청과 겹친 정상 NotFound 관측을 실패로 분류했다. 생성 성공 응답이 완료되기 전 종료된 NotFound인지 검사하도록 수정했다. 두 원본 응답과 시각을 유지하며 추가 GPU 실행 없이 재검증했다.

E02 부가 경고: 비대화형 SSH 설치에서 debconf가 Dialog/Readline을 사용할 수 없어 Teletype으로 전환하고 stdin 경고를 출력했다. 설치는 exit 0으로 완료됐고 Podman 반입·Pod 실행이 성공했다. 원본 설치 로그에 보존했다.

E07: Git 공백 검사에서 apt의 CRLF·행 끝 공백과 터미널의 끝 빈 줄을 검출했다. 원본을 편집하지 않고 해당 증거 파일에 한정된 -whitespace 속성을 추가했다. 기존 -text 정책으로 줄바꿈도 보존하며 해시 검증으로 원본 무결성을 확인한다.
