To restore a removed build file into a new destination:

```sh
restic -r "$BACKUP_DIR/restic" --password-file "$BACKUP_DIR/restic-password" \
  restore 309c7ee1 --target "$RESTORE_DIR"
```

The password file is private and must be backed up with appropriate access controls.
These are on-node backups, not an independent off-node disaster recovery copy.
