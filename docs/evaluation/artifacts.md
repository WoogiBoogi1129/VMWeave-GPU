# 증거와 산출물 관리

## Git에 포함하는 자료

소스·재현 도구·설정 예제·버전 고정 정보·보고서·선별된 공개 증거를 관리합니다.
기존 `experiments/evidence/results/` 묶음은 연구 근거로 보존하며 이번 정리에서 바이트를 변경하지 않습니다.
이 디렉터리는 `.gitattributes`로 줄바꿈 자동 변환을 방지합니다.

## 새 결과의 공개 기준

실행별 README에 목적·환경·SHA·명령·판정·한계를 기록하고 원본 및 SHA256 목록을 연결합니다.
새 대용량 묶음은 크기와 다운로드 경로를 검토해 Release 등 지속적으로 참조 가능한 저장소에
보관합니다. 일시 보존되는 Actions artifact만을 논문의 영구 증거 주소로 사용하지 않습니다.

문서 사이트에는 요약·선별 그림을 제공하고 원본 데이터는 GitHub의 특정 커밋으로 연결합니다.
사이트 그림은 원본 복사본과 해시를 [자산 목록](../assets/evidence/manifest.json)으로 연결합니다.

## 로컬 전용 자료

`.local/`, 로컬 `artifacts/`의 wheel·이미지 archive, 실행 중 `results/` 산출물은 Git에 넣지 않습니다.
키·kubeconfig·인증정보가 포함된 로컬 환경 전체를 증거로 공개하지 않습니다.
공개 묶음에는 재현에 필요한 환경 식별자만 포함하고 원본 판정을 훼손하지 않게 검토합니다.

## 인용

프로젝트 URL과 실험 커밋·결과 디렉터리·체크섬을 함께 기록합니다.
저자명·논문 제목·DOI가 확정되면 `CITATION.cff`를 추가합니다. 현재는 미확정 정보를 만들지 않습니다.
