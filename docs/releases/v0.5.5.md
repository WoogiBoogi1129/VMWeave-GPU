# v0.5.5 path-optimization release

Status: source prepared for publication; production rollout pending.

This release packages the combined VMWeave path optimizations validated in the 2026-10-27 campaign.
It preserves the v0.5.4 bulk-error fencing fix and environment-preserving installation.
The measured candidate is 34.3% shorter in completion time than the bulk-enabled options-OFF control,
but 10.0% longer than Flyt SHM overall. Deployment was explicitly requested after reviewing that result.
GPU Compute Sanitizer remains unqualified because the instrumented Worker did not reach readiness.

See [runtime configuration](../runtime/path-optimization.md) for Worker image defaults and required
Guest/Broker settings. Public artifact digests, production-quota canary results, rollout verification and
rollback identities will be recorded under `deploy/releases/v0.5.5.json` after validation.
Upstream HAMi and the current DRA installation are retained.
